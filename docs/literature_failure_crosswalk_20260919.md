## 结论

目前没有一个候选同时具备已核实的新颖性、当前数据可实施性和有效性证据。保留一个**纸面待论证候选**：面向有序 burst 条件关系的遮蔽预测适应。它不是已成立创新，也不是下一条训练 Job。其余常见提案不是已有机制重组，就是缺少必要信息，或重叠已停止路线。

本轮最重要的新核读发现：

1. NetAugment 已明确包含 incoming burst 大小变化、插入 outgoing burst 所造成的分裂、以及合并 incoming bursts。不能把“允许 burst 分裂/合并”直接称为新原理。
2. NetTTT §IV-D 已做无标签的内部表示重构，更新每流的 TTT adapter/cache。§VI-C 还报告去掉 payload 后严重退化（作者报告 AETC F1 99.87%→1.75%，ETCP 100%→0.04%）。这些数字不是本项目复现，也不能外推方向序列一定无效；但“删 payload、加入方向重构”不是有证据支持的直接移植。
3. PASLE §3 不只是保留低置信度样本：它用预测分数间隔生成单标签/候选标签集合，并逐步消歧。其命题依赖当前预测与目标后验误差受界的假设，不能把理论条件误认为漂移场景中已验证的保证。仅把错误 hard pseudo-label 改成 top-k 集合不是新方向。
4. ARM §3 明确讨论无标签边缘分布是否包含条件标签分布的信息；更多无标签样本本身不保证可识别正确更新。该信息条件是原理性提醒，不是本项目失败的已证明原因。
5. BECoTTA 已有输入相关专家路由和域增强初始化；共享干扰诊断又未支持本项目的普遍跨网站损伤，不推荐专家路由补救。

## 唯一保留的纸面候选：有序 burst 条件关系的遮蔽预测适应

### 问题与信号

工作假设（未验证）：序列上下文对被遮蔽 burst 属性的条件预测，可能提供区别于网站预测熵的适应信号。目标值来自当前已观测流量中被暂时遮蔽的部分，不来自网站伪标签；不需要payload、资源标签或跨日期source元数据。

这不声称burst关系已稳定，也不将合成遮蔽当作真实时间漂移。目的不是重建一个固定50–99 scalar，而是检验有序上下文是否具有有助于主任务的条件信息。

### 最小具体化（仅设计草案）

- 将相同有效包前缀编码成signed maximal runs，处理padding及截断。
- 源域有标签训练保留分类目标，增加上下文预测任务；候选可在已有编码器的中间表示接小型适配器，不保证可零成本插入既有checkpoint。
- 暂时遮蔽run长度或一段关系，预测其离散/对数长度目标。方向交替不是有价值的主要目标。
- 遮蔽必须发生在编码器之前，去除packet视图、总长度/位置等可能直接泄漏目标的旁路；否则只是复制输入。若不能设计非平凡且可实现的任务，淘汰候选。
- 部署时固定分类头及预定参数范围，以真实可观测的遮蔽目标更新适配器，再预测原始流量；不访问当前网站标签。

### 四项回答

1. 能力缺口：现有测试没有建立一个可靠的、非网站预测自强化的适应依据；不声称整个文献没有这种能力。
2. 可用信息：有序方向/run长度及其条件关系；目标可以自生成。但是否含额外分类纠错信息尚未知。
3. 潜在贡献：若能明确一种WF结构条件任务，并证明其更新改善真实时间漂移识别，而通用重构/普通联合训练不能解释收益，才可能形成贡献。当前“mask burst + adapter”本身不具备已确认新颖性。
4. 与失败路线差异：更新目标从网站entropy/稳定scalar/网站分组改变为序列内的可观测条件预测；不需要50–99可靠性、真实当前类别或普遍cross damage。但仅更换损失名称而保留同一信号不算不同。

### 最近先例与尚未解决的查重

TTT 已有辅助任务测试更新；NetTTT 已有流内重构；NetCLR/WF-TFC已有burst增强表示学习。因此这三者是必须跨越的边界，不是可拼接后直接命名的创新来源。当前40篇集合不足以排除masked traffic modeling、masked-autoencoder TTT、条件预测适应等外部近邻工作；未完成针对这些工作的定向查重前，创新资格仍为UNKNOWN。

### 若以后通过查重，最小实验怎样区分原理

不能只比较新模型与旧source。至少区分：普通CE；匹配额外训练CE；CE+同一辅助任务但不做测试更新；相同checkpoint开启测试更新；保持容量/目标边际分布但打乱上下文对应的控制；普通packet masking或通用重构对照。报告static、adapted、配对AG、修复/损伤及成本。打乱对照也会改变优化难度，不能单独作为因果证明。

成功需要实际分类净收益与适应增量，而不只是预测被遮蔽值更准；若只是联合训练更好，应收窄为表示学习结果，不能写成适应机制。如果破坏上下文后收益不变、简单重构同样好、或必须加目标标签才能有效，就停止当前创新主张。

本草案会涉及新训练，当前尚未获实验预算授权；不自动执行。TemporalDrift继续是开发集；外部测试保持封闭。同池适应评价需另行冻结协议。
