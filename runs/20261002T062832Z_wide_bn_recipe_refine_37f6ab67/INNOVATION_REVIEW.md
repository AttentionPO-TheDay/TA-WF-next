# 当前网站指纹生成器设计的创新性审查

审查范围：本项目本地文献矩阵、`RESEARCH_ASSESSMENT.md`、`docs/literature_failure_crosswalk_20260919.md`，以及当前已完成的生成器实验。该审查是有限查重，不是穷尽检索或专利意见。

## 结论

目前不能把“逐级卷积＋BatchNorm＋Transformer”本身称为已确认原创方法。网站指纹领域已有 CNN/Var-CNN、Transformer、局部或 burst 表征、对比/一致性学习、少样本迁移和时间漂移适应先例。当前实验真正有价值的结果是：在本项目固定 TAM 输入和源期协议下，新的逐级生成器使 Transformer 验证准确率从 77.647% 提高到 86.536%，加入 BatchNorm 与容量扩展后达到 89.150%。这证明本地有效性，不等于文献新颖性或跨数据集通用性。

当前较有潜力的贡献单位是“网站指纹生成器作为统一接口，并针对时间漂移设计可观测、受限的调整机制”。但它只有在以下证据成立后才可能构成方法贡献：同一生成器接口适配不同输入权限和分类头；冻结生成器权重可被另一头复用；漂移调整只使用部署时可见信息；在未参与方法选择的外部时间数据上保持收益；并且相对已有 Swallow、WF-TFC、NetCLR/NetTTT、Proteus、OnlineWF、TFAN 等方法有清楚的失效机制差异。

## 已有先例与当前差异

| 当前元素 | 文献/已有实现覆盖 | 当前可主张内容 |
|---|---|---|
| 多层局部卷积、CNN 特征提取 | Var-CNN、RF、DF及大量 WF backbone | 这是实现选择，不单独构成创新 |
| Transformer 对 token 建模 | 本项目旧实验及通用流量/WF Transformer 路线 | 当前组合在固定 TAM 上的实证增益 |
| BatchNorm 稳定训练 | RF、Meta-TTT 等直接使用 | 本轮 BN 对当前生成器的增益证据 |
| 多尺度/局部 burst token | NetCLR/NetAugment、WF-TFC、DNNF、TFAN 等近邻 | 需要明确不同的输入权限和漂移失效机制 |
| 训练期生成器＋分类器联合学习 | 普通监督表征学习及本项目已有模型 | 不能称“生成器反馈学习”本身为新原理 |
| 时间漂移调整 | Proteus、Swallow、OnlineWF、NetTTT、TTT、TFAN、WF-TFC等 | 必须提出不同的可观测信号和公平预算 |
| 局部/条件遮蔽重构作为调整信号 | TTT、NetTTT及本地审查保留的候选 | 仅改名为 masked burst prediction 不足以形成创新 |

## 当前最可信的研究定位

“一个面向网站指纹流量的可学习 token 生成器”可以作为系统设计目标；“通用”应先限定为方法和接口通用，而不是一个已训练权重直接跨所有数据集。当前已证明的是联合训练时在一个已观察数据集上的跨分类头结构收益。尚未证明权重迁移、缺时间戳输入、跨数据集、外部时间漂移或在线调整。

真正可能形成贡献的部分是生成器与漂移调整之间的接口设计。例如生成器输出有序、局部、可冻结的 token，调整器只更新预先定义的小参数集合，并以流量自身可观测的结构任务作为信号。这个想法仍与 TTT/NetTTT/稳定表示/少样本适配有明显近邻，必须通过针对性查重和对照实验建立差异。

## 需要补的证据

1. **权重可复用性**：冻结 wide+BN 生成器，重新训练不同分类头；与随机生成器和同头联合训练对照。
2. **输入权限**：去掉绝对时间数值，只保留方向序列，验证统一接口是否仍工作；不能伪造缺失时间信息。
3. **跨数据集**：冻结方法、输入规则、选模和预算后，在 WTT-Time/AWF 的合规部分评价；未来测试前先完成使用历史审计。
4. **漂移机制**：在 TemporalDrift 开发日期上冻结基础模型后，比较静态模型和只更新生成器小适配器的规则；适应输入与标签权限必须预先冻结。
5. **直接近邻对照**：至少包含 Swallow/WF-TFC/NetTTT 类别中的可实施基线，不能只和当前自有旧模型比较。

## 不应写成的结论

不能把高验证准确率写成“首次提出通用生成器”；不能把逐级卷积、BatchNorm、Transformer 或生成器＋分类器联合训练单独写成原创原理；不能把当前 89.150% 固定验证集结果写成跨时间泛化；不能在看到外部未来结果后再修改方法并继续宣称独立确认。

审查结论：**工程组合的新颖性风险高；面向时间漂移的统一接口和受限调整机制具有待论证的研究空间，当前状态为候选问题，不是已确认创新。**
