# 实验结果

## 结论（2026-09-22）

完成23个文件、475683行视图记录的显式只读内容审计，无训练、适应、性能评分或新划分。不是475683独立trace。原始数据未修改，Temporal/OpenWorld/Defense/WTT/AWF未读取。

048/drift内明确恢复045=25128、046=19237、047=20041，分别覆盖102类。对应其他版本的train/valid数据被重用于该目标视图，而不是新增独立采集数据。可为未来048→045/046/047构建“精确匹配恢复的子集协议”；它不等于原论文完整目标、也不保证恢复子集对未匹配部分无选择偏差。

修正上一轮限定：并非只能研究聚合版本目标，现在已有分版本子集可行性的直接内容证据。身份可信性依赖官方目录角色，仍非独立capture manifest。若用多个版本训练，须排除所有其训练/验证锚点重用，不能把匹配目标再充当独立测试。

逐行证据：artifacts/version_{045,046,047,048}_identity.csv。记录row、label、content_id、匹配版本、状态和标签冲突。不自动生成训练/测试拆分。

### 2. Network/Behavior：内容级隔离可用，仍非session独立证明

23个文件各自完整trace重复副本均为0。Network/Behavior的11个文件各自前5000方向输入重复副本也均为0。该两组之间仅以下已知完全重用：

- Behavior train = Network train：16146条；
- Behavior valid = Network valid：1795条；
- Behavior test = Network SG：1994条。

除此之外，两组内及两组间所有文件配对在完整trace和前5000方向两种表示均无交叉重复；该家族内异标签内容冲突为0。上述测试是相等性测试，不证明近重复、独立session/circuit或原始trace-family隔离；5000方向审计不覆盖未来其他观察预算。

### 3. URL：须防止重复页面跨角色

Behavior subpage共20400行、17739个精确URL；2661个额外重复副本，1344组URL重复，单URL最多100条，跨标签URL冲突为0。URL相同不等于trace相同。

后续若划分subpage开发/适应/query，需先决定是否要求未见页面；若要求，应按URL成组隔离。若允许同页重复访问，则明确报告此任务，不冒充新页面泛化。homepage文件没有URL字段，不能验证其与subpage的URL级交叉。未进行URL规范化、路径去参或注册域合并。

### 4. 新发现：时间字段不能直接用于未经审计的IAT token

每文件固定等距抽32行，共736行视图样本（不是736独立trace），其中459行的非零abs(timestamp)出现下降。23个文件均有该现象。该抽样中无非有限值、无内部零后又出现非零。它不是全量数值质量认证。

此时不能把有符号时间戳按存储顺序直接diff后称为可信物理IAT，不能默默排序或截负值为0来掩盖现象。需后续检查回退幅度、方向关联、原始处理/排序语义；也不能据此直接判定时间信息无用或数据损坏。

### 5. 暴露与完整性

详见EXPOSURE_REVIEW.md：限定旧配置/报告检索没有发现三组性能实验记录，但不能证明没有别名、外部记录或未保存运行。旧审计和本轮都已使用数据；不得称从未见过。当前标签仅用于内容身份/冲突审计，不用于模型、性能或选参。

verify.py检查310503条版本manifest、23文件数量及重叠计数一致性，0 errors；产物SHA256见artifacts/integrity.json。此验证是产物内部一致性检查，不是独立重跑全量内容匹配。脚本编译通过。单进程CPU，借用旧venv的numpy，不导入旧训练实现。

## 对共享生成器的影响及下一门槛

Version/Network/Behavior可以作为不同条件的候选场景，不需要为每种漂移新写一个tokenizer。共享方向结构接口仍是可行起点，但这里没有证明其性能或稳定性。时间属性暂设为待审计可选通道，不贸然生成duration/gap/rate。

正式训练前还需要：冻结各场景开发/留出用途、Version仅使用可信恢复子集及重用排除、Behavior页面级角色规则；数值/有效长度检查应在选定预算下全量完成。当前只完成数据门槛审计，没有授权或运行训练，也未创建新数据split。
