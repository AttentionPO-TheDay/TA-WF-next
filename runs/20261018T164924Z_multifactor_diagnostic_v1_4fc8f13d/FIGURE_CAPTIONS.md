# 论文二诊断图表说明

Table 1（多因素原生影响诊断）。仅由18,553条TemporalDrift源训练样本训练的wide_bn，在四个明确归因版本、五个地域切片与深层URL切片上的冻结模型表现。报告三个训练seed的均值及样本标准差。Version按恢复出的版本身份归组并去重，不按drift文件所在目录命名目标版本；其样本复用了版本锚点，不是独立新采集。Network仅具有地域信息，不解释为已知丢包率、RTT或jitter的干预。Behavior每个精确URL保留一条代表trace。102类分类指标依赖历史相同内容支持的标签对应假设，不能替代官方homepage↔subpage身份映射。与源valid的保留率仅是描述性参照，源valid曾参与选模。

Table 2（对齐消融）。所有条件使用相同reference/query清单，三个源训练seed独立重置；每切片1,024条无标签reference，query仅用于终点评分。比较frozen、TENT BN、熵门控、AdaIN、旧残差projector、关闭拓扑项的原型方法及完整原型方法。除无优化的frozen/AdaIN外，统一固定800步；不以query挑选checkpoint。NAR为frozen原正确样本中被适应改错的比例，Recovery为frozen原错误样本中被纠正的比例。TENT BN在query前向使用批统计量，属于额外声明的transductive-forward对照。Behavior的hostname NMI/ARI作为事后分区诊断单列在CSV中；hostname没有输入适应损失。

Table 3（外部方法迁移，原样复用v4）。WTT-Time和AWF分别在其获准历史训练部分训练独立方向模型，报告冻结配方的全部144个单元，含阴性结果和WTT 2022-02-16严重退化切片。19/21和14/15是熵门控相对frozen的逐seed×切片正ΔF1单元数，不是识别准确率或独立重复的显著性。该表没有评价新原型方法，也不证明Temporal闭集分类器能跨数据集类别直接识别。外部反馈已影响本轮方法提出，不能再把同一测试部分视为新方法未经反馈的确认数据。

雷达图（十切片frozen Macro-F1）。各轴是0–100%的相同量尺，保留全部十个预定切片；雷达面积没有物理量纲，不作为因果破坏权重或综合安全分数。三类因素的等权汇总另存CSV，不让版本样本数决定总权重。
