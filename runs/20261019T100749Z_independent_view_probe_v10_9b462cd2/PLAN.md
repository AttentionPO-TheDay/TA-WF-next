# 独立表征能力与条件错误互补性 v10

本轮依据v9弱PCA视图失败，检验源监督独立编码是否提供有效语义与条件错误互补性。用户明确授权下一步实验；新增源分类器训练预算在此冻结，不改变18,553纯净源底座或旧结论。仅Version045与USA已观察诊断切片，不能称盲测或独立确认；地理切片不代表已知丢包/时延。类别身份沿用内容支持的102类对应假设，非官方映射。

三个独立新编码器视图：方向顺序(主候选)、方向+非负包间隔(次候选)、同TAM输入CNN(架构对照)。同Conv/GN网络、初始化/源采样流、训练30轮/AdamW/源标签预算。由已锁定prepared.pt读取纯source18553与officialvalid2160；全部新训练从头开始，不使用主模型标签预测作蒸馏或任何目标标签。验证每两轮，最高valid MacroF1最早strict improvement选模；固定温度网格只以valid NLL选择。三个seed42/100/2026对应GPU0/1/2，合计9模型，禁止query反馈追加训练。注意：这是额外源监督模型预算的能力探针，不是对零成本LoRA的公平优越性结论。

输入只使用各行已冻结first5000 timestamps/TAM；方向保留顺序且去掉时间，IAT版增加有效相邻包非负时间差，负差裁0且记录比例，不将时间误作包大小；TAM log1p两方向计数。同一raw记录但改变归纳偏置，不能预设误差独立。零时间沿用旧缓存padding语义，潜在真实t=0包不可恢复的局限如实注明。无输入统计拟合，无query BN/投影/中心/温度/CDF拟合。

所有9训练及sourcevalid重载完成之后才统一执行query终端评分。reference1024只前向，独立query沿用不可变清单。三种输出：独立视图原始预测、固定等权温度校准概率融合、PCA历史只读对照。测量源valid能力、两片frozen错误纠正、固定共错子集纠正/同错/其他错、误差相关/重合、分歧改写精度和纠错/损伤计数。按两种预注册分数画query标签诊断前沿，主分数视图probability margin；NAR<=1%的操作点含query标签信息，不是可部署风险阈值，不重启更高分位拒绝分支。与v9 smooth历史前沿比较仅作能力筛查，并明确额外训练预算。

门槛：每个arm各自三seed源validF1>=60%；两个切片三seed平均共错纠正>=10%、主分数分歧纠错vs损伤AUROC>=.65、Rec@NAR1比v9smooth>=+.5pp。主判决仅direction_order，不用表现更好的次候选冒充主候选。全量输出所有seed和阴性结果。门槛通过亦不自动接入适应；本轮不训练LoRA、BN、主backbone，不访问WTT/AWF，不复活去KL/高分位拒绝分支。

预算9新源模型、30轮固定、45分钟/2.25 GPUh/3GiB；每模型750秒上限。训练前SHA冻结代码/配置/计划/数据和历史指标，预检输入规则/梯度/空通道/批无关性，checkpoint源valid重载、全部目标logits逐状态独立重载和指标复算，最终输入输出SHA封存。遇实现错误保留失败日志并记录同配置修复，不做反馈驱动调参。

运行修复记录：首次预检在任何训练前因PyTorch CUDA adaptive_avg_pool backward不支持严格确定性失败。以完全相同的8-bin区间平均改为确定性slice mean，CPU参考前向及梯度等价核验；数学模型和全部超参数/预算不变。失败日志与原freeze保留为freeze_preflight_failure.json，新代码重新冻结后同配置重跑。
