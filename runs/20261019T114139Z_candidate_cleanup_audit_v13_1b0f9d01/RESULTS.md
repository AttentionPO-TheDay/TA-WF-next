# 候选清洗审查 v13

已完成固定 v9/v12 缓存审查；无训练、无新前向、无新评分或部署阈值。以下是已观察两切片的事后诊断，不是独立确认。

## 审查结论与下一步边界

1. Version 新增接纳均值为 R=141.333、D=38.333、W=279.000，同时移除 R=102.333、D=39.667、W=192.667；净变化为 R+39、D−1.333、W+86.333。不是只增加误改：纠错和接纳广度同时提高，但新增候选的纯度不足。USA 净变化为 R+14、D−0.333、W+16。
2. 同 v9 纠错数时，Version 的 W 为914.333→922（+7.667），D为128.333→115.333；USA 的 W为102.667→90.333，D为14.333→10.667。两个切片每个seed的D都下降；Version同纠错W为2个seed升、1个seed降，USA为3/3下降。故不能说整体清洗失败到没有价值，也不能说Version纯度问题已解决。两片同纠错的R_overshoot均为0。
3. 候选否定与确认存在可观察的分离。控制v12主分数十分位后，边界R/W的“否定旧类”AUROC仅为Version .3455、USA .3409；候选log概率为 .6320/.6441，候选相对第三类裕度为 .6398/.6554，后两者在全部6个切片-seed状态均>.5。这支持“当前相对证据可能通过旧类支持崩落而虚增，需额外确认候选”作为后续假设，不是因果证明。
4. Version 新增W样本中，辅助集成最支持第三类的比例均值67.44%，新增R中为40.78%；候选平均概率分别 .2333/.4176。USA相应第三类获胜率为61.09%/29.91%，候选平均概率 .2651/.5090。第三类获胜不是可直接硬拒绝的准则：新增真正纠错中也占有明显比例。
5. 不能靠删少数网站解决：Version新增W涉及每seed67–81个真实类别，前五真实类别占比仅18.5%–21.1%，低于原接纳W的24.5%–28.5%。这种类别统计仅用于诊断，不授予类别黑名单策略。
6. 中段可分性尚未变成极低误接纳尾部优势。在边界R/W的局部ROC中，候选log概率 pAUC/.01 为Version .0253、USA .0000；第三类裕度为 .0234/.0115。这里FPR分母是W，不是全部frozen正确样本，因此不是NAR。USA边界仅22–29个R和57–69个W，1%W对应不到1个负例，尾部估计分辨率很低，不能把约.65的整体/分层AUROC当作NAR1可兑现收益。
7. 源valid边界R/W在全部6个状态至少一组不足20，不能据其接近.9的AUC直接选阈值或宣称迁移可靠；同一sourcevalid在两片中重复使用。现有源valid缓存不足以支撑可靠的清洗器训练。

建议后续冻结一个小预算验证：保留v9候选与原低NAR风险排序，以候选绝对支持及相对第三类裕度作为“确认候选”分支，先在源train及预先规定扰动上构造R/D/W监督，源valid校准，目标标签仅终端评价。是否采用任何新权重/模型/阈值必须在新版本执行前另行冻结；本轮不训练、不把诊断方向自动写回评分。验收仍要求同NAR增纠错、同纠错减W且D不升，并报告极低风险前沿；不恢复去KL或高分位拒绝分支。

## 权限与解释边界

边界集合依赖 v12 已有 query 标签选择的操作点，因此以上是条件化诊断，不是无监督部署协议。源valid在两目标状态中重复，只作控制，不能与query或彼此合并为独立重复。

没有用标签训练评分器、翻转特征方向、选择新阈值或给出误改概率。分层AUROC的条件化不构成因果证明；小样本分层、网站间依赖和仅3个seed限制结论，不作显著性声明。

全部类别分布（真实/旧预测/新候选）、新增/移除接纳、辅助第三类获胜情况、相关性、两种错误对照及sourcevalid结果均已保存，不能只摘取有利特征。原评分和候选类别保持不变。
