问题：候选漂移数据集能否按输入语义、类别体系和漂移因素筛选后组成联合训练池？

范围：只读 CPU 数据兼容性审计，不训练、不微调、不执行 TTA，不读取 query 标签用于选模，不访问或评分外部未来测试。候选包括 TemporalDrift、VersionDrift、NetworkDrift、BehaviorDrift、Defense、OpenWorld、AWF、Shusterman 和 WTT-Time；PCAP 仅作来源/格式盘点，不进入闭集联合训练候选。

检查内容：
- 文件存在性、格式、大小和角色目录；
- NPZ 内部数组名、dtype、shape 和 schema 签名；HDF5/PCAP 只做容器与路径级盘点；
- 输入模态与数值语义（方向、时间戳、包大小、TAM）；
- 训练/验证/漂移/测试角色线索；
- 类别映射和样本级重复的可审计边界；
- 共同方向子表示、同模态包大小表示、数据集专用前端/分类头的候选组合；
- 输出联合 manifest 所需字段和未解决风险。

权限：仅读取共享数据和已有配置；不写入共享数据；输出全部归属本 run。当前结果只用于结构与可行性判断，不改变任何数据集的确认资格。

预算：CPU、标准库、单进程；不申请 GPU；停止条件为所有候选目录完成盘点，或出现不可读取/权限错误时保留部分结果并标记失败。
