# 源域候选确认重排 v14

假设：v13中候选绝对支持/第三类裕度的R/W区分线索，能通过源域固定扰动训练的小型三分类重排器迁移到目标，并在v12风险排序基础上减少无效改写。当前未验证。

数据：唯一监督源为既有pure source prepared.pt中的18,553训练行及既有2,160 valid行。训练按各类sha256(v14|train|原行号)最小24条，102类共2,448；验证各类sha256(v14|valid|原行号)最小8条，共816。它们是已观察源数据的固定子集，不是新确认集。原模型已在18,553行训练，重排器训练输入不具备独立模型外预测资格，应报告源过拟合及合成到真实迁移风险。

固定5种源输入：clean；时间×.7且删10%；时间×1.4且删10%；删25%且保留剩余前75%；删40%且保留剩余前60%。删包用行号/原位置/固定case与role盐的确定性哈希，保留首个非零元素，稳定压紧；截尾向上取整，时间戳不排序。均按既有方向/80秒/1799-bin规则重建TAM。仅为合成扰动，不宣称等价真实丢包率或物理机制。标签继承原网站类别，强截尾可能不保留可识别信息，需承认该限制。

冻结网络：三个pure wide_bn、六个v9 smooth_balance适配器、三个v10 direction_iat模型均只前向，不做任何更新。显式最小实现写入run内，并以全部sourcevalid缓存逐位复现冻结与适配输出、margin以及辅助输出后才生成数据。辅助使用与v12相同的三seed×五视图、温度、权重；候选始终v9 Top1，主模型及BN完全冻结。

训练：每个seed/目标适配器各一个source-only重排器，候选changed中分R=原错→正确、D=原对→错误、W=原错→其他错。主重排器输入3维：v9 normalized margin delta、候选平均log概率、候选相对排除旧/新类后的第三类裕度。对照只用margin。按changed源训练行拟合均值/SD，SD下限.001；multinomial LogisticRegression，C=1、L2、class_weight=balanced、lbfgs、max_iter2000、tol1e-8，固定最终解，不选epoch/C/特征。每个源训练状态R/D/W至少25，否则整个实验作为可行性失败在目标评分前停止，不按反馈增加数据/扰动。

三分类产生u=g_R-logsumexp(g_D,g_W)，并以源changed训练u均值/SD标准化。最终分数固定为v12_primary+.25*z_train(u)。margin-only对照同式。平衡分类器输出不是校准的物理误改概率。不在目标拟合任何系数、归一化或阈值。

源验证校准：固定816×5验证输入，每评分采用完整同分前缀、NAR≤1%，最大化U=R-D-.25W；要求R≥10且U>0，否则拒绝全部；平局先少D，再高阈值。该规则只是一种源域校准方案，不承诺目标风险。所有源训练/验证及模型JSON散列封存后才打开目标评分。

目标：只读取v13已封存Version045/USA的逐行特征及v12评分缓存，3源seed×2片×4评分=24状态；目标没有新前向。主对照v12_primary，另报v9_margin和margin-only训练对照。目标标签只用于终端pAUC、确定性低NAR前沿、同纠错/同实际NAR的R/D/W，以及冻结源阈值实际指标；不拟合、不选新模型/参数/阈值。query选出的诊断操作点不可部署。源valid原数据曾用于checkpoint/温度/v12权重，本轮validation仍非独立确认。

预注册主判据：两片均要求相对v12归一化pAUC不降、Recovery@NAR1下降不超过.1pp，并至少满足(1)相同v12实际损伤预算下Recovery提高≥.2pp，或(2)达到v12纠错数的最小完整前缀(约束NAR≤1%)中W至少减少5%、D不升。完整报告各seed及辅助指标；不把最佳对照替换主候选。源阈值策略另报是否所有6状态NAR≤1%且Recovery>0，不自动整合部署。

执行：GPU0/1/2分别处理一个已有source seed的源前向；最多30源缓存、12个线性重排模型拟合，CPU线程2。预算1800秒/1.5保守GPU小时/1GiB，不训练任何主网络或辅助网络。目标旧结果不修改，WTT/AWF关闭。输入与代码先冻结；实施错误须记录后按同配置修复，不因性能改变方案。

审核：全部sourcevalid原网络/适配器/辅助输出复现，30源缓存每个完整首256行独立重提取；12重排模型JSON载入后全源分数复算；24目标状态特征与指标重算、独立混淆/同分阈值计数；保存行清单、扰动定义、缓存、模型、预测、前沿、报告和散列。每个角色/扰动重复同一网站trace不能当成独立样本。

实施修复1：第一次预检遗漏原v9的MHA fastpath关闭设置，导致源valid logits出现小差异（seed42最大.006452，Top1不变，生成器token精确一致）。在任何源扰动生成、训练或新目标评分前停止。恢复原推理设置，仍要求逐位一致，不放宽容差；配置/特征/预算/判据不变。旧freeze、失败日志和repair_history保留。
