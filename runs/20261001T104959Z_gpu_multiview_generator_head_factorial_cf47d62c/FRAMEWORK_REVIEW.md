# 生成器与模型框架的阶段性决策

日期：2026-10-01。此文依据用户本轮目标、PROTOCOL.md v1、HANDOFF.md 和已完成源期实验。它是本轮架构决策依据，不是实验结果，也不授权未来数据评价或漂移适应训练。

## 研究目标与两阶段边界

用户希望先设计自己的“流量生成器 + 分类模型”，再针对这套系统研究缓解时间漂移的调整机制。近期提升成熟 RF 的成绩不能替代前一目标；独立编写代码也不能自动构成原创研究贡献。

第一阶段建立基础模型：固定当前源期训练/验证数据，目标为三个训练 seed 的平均 valid accuracy ≥90%，同步报告 Macro-F1、各 seed 和训练拟合。生成器收益、Transformer 收益及90%绝对性能目标分别裁决。验证集已经反复参与开发，达到90%只能作为源期开发目标达成，不等于独立确认的泛化保证。

第二阶段建立漂移机制：在明确权限的 TemporalDrift 开发日期上研究基础模型随时间变化的问题，再为参数更新或维护方式设计匹配对照。先冻结阶段一模型及静态对照，再登记阶段二新实验的数据、标签、更新范围、reference/query 隔离、选模与预算。当前实验不实现或检验 TTA、路由器、参考库或伪标签机制。

90%是用户提出的工程性能目标，不是证明抗漂移的前提定理。若有界开发后达不到90%，应报告差距及原因候选，由证据决定是否继续基础模型开发，不能把较低起点引起的较小绝对下降称为抗漂移效果。

## 本轮2×2实际问题

本轮拟固定相同完整方向+时间输入、source 每类150条及固定510条 valid，对比生成器因素与分类器因素。生成表示为100个 packet 局部方向/时间统计 token 与120个 TAM 计数 token，共220个 token；可学习条件在相同聚合之前加入局部 CNN，固定条件使用预定统计。精确维度、切分、时间换算、padding 与 mask 以冻结后的 PLAN.md、config.json 和运行代码为准。

|条件|生成器|分类器|作用|
|---|---|---|---|
|A|固定统计|逐 token MLP + 同规则汇聚|输入及固定表示对照|
|B|固定统计|Transformer + 同规则汇聚|固定 token 上的关系建模|
|C|可学习局部编码|逐 token MLP + 同规则汇聚|局部编码的增量|
|D|可学习局部编码|Transformer + 同规则汇聚|目标组合|

“固定”指原始流量到统计特征的提取规则固定；共享的特征投影、分类器及读出仍接受分类梯度。不能把新增投影本身重新命名为生成器创新。

固定和可学习条件虽然输入信息及 token 数相同，其局部细节保留、有效表达自由度和参数量可能不同。因此 C−A、D−B识别的是“此局部可学习编码设计的整体增量”，不能仅凭正向结果证明梯度更新本身是原因。若此增量稳定成立，冻结/随机但不训练的同结构局部编码器才是后续区分学习与结构信息保留的必要候选；本轮不额外增加第五条件或结果后追调。

同样，Transformer 与 MLP 参数量/关系表达不同；配对 seed、输入、样本顺序、梯度步数和选模次数能降低混杂，但不能宣称所有有效容量完全匹配。记录每条件生成器/分类器参数量与耗时。两个视角同步存在还不能证明互补性或哪一视角贡献了收益；若组合确实有效，视角消融应另立有界实验。

## 四类裁决须分开

1. 生成器收益：分别报告 C−A 与 D−B。按 PLAN 预定相对门槛及逐 seed一致性判断，不能只看训练准确率或挑一个有利分类器。
2. Transformer收益：分别报告 B−A 与 D−C。Transformer只有在对应token条件下显示预定增益，才有本轮继续使用的性能依据。
3. 组合交互：报告 `(D−C)−(B−A)`，观察可学习token是否使Transformer更有用。仅D胜A不能证明组合协同；三seed不足以稳定估计复杂交互，保留数值与限制。
4. 绝对成绩：三个seed平均accuracy是否≥90%；同时列出与历史RF85.948%及方向CNN73.987%的差距。RF训练配方、表示、选模预算不同，该比较是开发性能参照，不是严格匹配的机制归因。accuracy绝对目标与Macro-F1相对门槛不能互相替代。

训练seed是优化重复，固定valid并没有三个独立数据集。首次本轮未来评分前才冻结后续评价；本轮源期结果不能回答哪个条件更抗漂移。

## 整体框架如何按结果调整

|本轮结果|下一步框架决定|
|---|---|
|生成器收益和D−C均通过，D具备有竞争力的绝对成绩|保留双视角可学习生成器+Transformer；先验证收益来源，再冻结为漂移机制的基础系统|
|生成器收益通过，但D−C未通过|保留生成器，采用C作为当前性能基线；Transformer保持候选。研究主体可以是生成器+轻量分类模型，不能把未来漂移收益归给尚无收益的attention|
|B明显更好而生成器增量未通过|固定token+Transformer作为诊断基线；当前局部CNN接法不采用。重新限定生成器的学习任务，避免为了名称把可训练投影算新贡献|
|两因素均无稳定收益，但新的固定时间表示整体明显更高|优先研究表示及接口；后续比较方向/时间信息，而非堆叠更多分支和层数|
|四条件均明显低于RF且差距稳定|承认当前token化/读出路径可能有较大损失；下一轮选择一个受控表示或汇聚问题，必要时改为保留有序二维时间计数的编码框架。不能同时换编码器、分类头、增强及配方后归因|
|均接近RF但未到90%|暂不切换整个框架；依据训练/验证曲线和共同错误，冻结一次有上限的优化或数据覆盖诊断|
|超过90%但生成器或Transformer归因门槛未过|只登记性能目标达成；架构贡献仍未证实，不因绝对分数高而补写协同结论|

框架切换应依据本轮结果与新实验预定问题，不能按单seed最优分数选择。不要把保持Transformer当成研究成功的必要条件；用户真正要的是有依据的自有生成器与分类系统，以及作用于该系统的漂移机制。

## 为漂移研究保留的接口

阶段一实现宜明确区分：输入适配→每视角编码→token与mask→分类器→读出。模块化允许将来冻结部分编码器、限定参数更新范围，或比较固定token与更新token，但这些只是接口能力，不是本轮已验证的适应机制。当前不加入额外adapter、teacher或在线更新损失。

时间token可能依赖网络延迟，既可提升源期判别，也可能随采集条件变化；不能预先把时间视角称为不变量。阶段二需要分别报告静态未来绝对性能、从源期下降幅度和同一基础模型下机制增量，才能避免起点差异混淆。

WTT-Time/AWF不具备本项目可直接复用的逐包时间戳。若最终方法依赖时间，须声明为时间可用场景，或在外部评分前定义并验证方向核心版本与缺失模态处理。不能伪造时间，不能把方向版本外部结果视为时间专属机制的直接验证。不同输入版本对应不同冻结方法，逐项记录。

TemporalDrift未来日期历史上已经用于开发。即使当前数轮实验关闭未来，它们也不会重新获得未见确认资格。WTT-Time/AWF确认资格按PROTOCOL逐部分审计，不自动假定可用或失去资格。

## 本轮实施审阅项

发布前检查完整方向+时间语义与RF接口审计一致，禁止排序或隐式修复时间；所有条件覆盖相同5000包权限及全部有效输入。统计、尺度估计只能用获准source，valid标签只选模/评分；padding、token mask与空视角保持batch独立。记录固定/可学生成器何处收到分类梯度，确认固定提取没有梯度参数。

配对运行检查共享分类器权重、视角/位置嵌入、读出初始化、训练样本清单、增强随机流、选模机会、梯度步数和学习率规则。可学习CNN的初始化不应挤占分类器随机流；参数量不能仅给总数。有效token不应因固定/可学条件而变化。

所有任务均须保留完整曲线、配置、最佳checkpoint、source与valid预测及独立重载指标。预算停止、错误修订和阴性结果一并报告。本审阅文未读取新数据、启动训练或实现漂移机制。

### 初版代码审閱（发布前）

已只读审阅本run的 `model.py` 与 `prepare.py` 初版；未运行模型或打开新数据。实现把固定统计保留在可学习条件中，在同一投影输入中增加80维局部CNN特征，因此应称“固定统计+可学习局部特征”对照“仅固定统计”，不是用学习完全替换统计生成规则。固定条件的80维为零，局部CNN存在但被冻结且不运行；总参数量相同不代表可训练自由度相同。

所有条件均构造CNN后再初始化共享投影、位置/视角嵌入及分类头，分类器选择用隔离随机状态构造，设计上避免新增CNN或分类器类型扰动共享初始化。运行预检仍需核验共享权重逐tensor相等。packet mask独立于生成器因素；120个时间token始终有效，空bin保留为“无流量”信息，并未按padding删除。Transformer无全空注意力行，因为时间token始终有效。

两个视角各自均值汇聚后拼接，保证时间token数较多不会在统一平均中直接挤压packet权重；这种读出也限定了本轮所检验的跨视角接法。局部编码仍有信息损失：packet每10包聚合一次、时间计数每3bin聚合为局部特征再合成15bin token；固定时间统计保留每15bin全部30维计数。故阴性结果不能推广到所有时间表示或学习边界生成器。

数据准备明确复用上轮source/valid行和TAM缓存，并拟逐行独立重建计数，禁止排序与跨方向差分；80秒截断及混合方向时间回退属于既有输入语义限制。检查这些事实只能支持当前TemporalDrift接口，不证明跨数据集时间通用性。
