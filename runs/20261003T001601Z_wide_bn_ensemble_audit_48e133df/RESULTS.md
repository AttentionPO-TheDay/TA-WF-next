# wide+BN 集成审计结果

本实验没有训练新模型，只读取已经完成并审计的三个 wide+BN Transformer、三个 progressive MLP 和三个 matched RF 的最佳 checkpoint logits。融合规则、权重和 tie-break 在执行前固定，valid 没有参与融合权重选择。

| 方法 | source accuracy | valid accuracy | valid Macro-F1 | valid correct |
|---|---:|---:|---:|---:|
| wide+BN 单 seed 均值（3 个 seed 的指标均值） | 99.927% | 89.150% | 88.944% | — |
| wide+BN raw-logit 平均 | 100.000% | 90.588% | 90.504% | 462/510 |
| wide+BN 逐样本 z-score 平均 | 100.000% | 90.784% | 90.630% | 463/510 |
| **wide+BN 固定多数投票** | **100.000%** | **91.569%** | **91.435%** | **467/510** |
| wide+BN/MLP z-score 25/75 | 100.000% | 89.020% | 88.806% | 454/510 |
| wide+BN/MLP z-score 50/50 | 100.000% | 91.176% | 90.942% | 465/510 |
| wide+BN/MLP z-score 75/25 | 100.000% | 91.765% | 91.643% | 468/510 |
| wide+BN/RF z-score 25/75 | 99.824% | 93.529% | 93.490% | 477/510 |
| wide+BN/RF z-score 50/50 | 99.974% | 94.118% | 94.022% | 480/510 |
| wide+BN/RF z-score 75/25 | 100.000% | 94.118% | 94.031% | 480/510 |

表中 MLP/RF 行的命名按 `wide+BN 权重 / 另一模型权重` 解释；RF 行是强对照融合诊断，不计入自有生成器模型成绩。

## 主要结论

三个 wide+BN seed 的固定多数投票将 valid accuracy 从单 seed 平均 89.150% 提升到 **91.569%**，提高 **2.418 个百分点**，467/510 条正确，超过 90% 线。这是当前自有 wide+BN 系统的集成候选结果，不是单个生成器或单个分类头达到 90%。逐样本 z-score 平均也达到 90.784%，说明 seed 间的预测分歧确实包含互补信息；多数投票收益更大，说明若干样本的 logit 置信度尺度会干扰简单平均。

若允许组合两套自有分类头，固定的 wide+BN 75%＋progressive MLP 25% z-score 融合达到 **91.765%** accuracy / **91.643%** Macro-F1，为本轮自有模型组合的最高值。它证明分类头之间存在互补错误，但不能解释为单一 wide+BN 生成器提升；后续部署需把它登记为独立的多模型集成版本。

wide+BN 三 seed 在 valid 上有 85 条样本存在预测分歧，三 seed 错误的并集 oracle 上限为 94.902%；这只是错误互补诊断，不是可部署 oracle。wide+BN 与 matched RF 的错误并集为 97.451%，表明 RF 仍携带额外信息，但 RF 融合结果不能改称为自有生成器性能。

## 核验

- 无训练、无 GPU、无 future/WTT-Time/AWF/TTA 访问。
- source/valid 行数分别为 15300/510，类别数为 102；所有 logits 与标签按同一冻结缓存对齐。
- 9 份输入 logits 和 prepared 数据的 SHA-256 已写入 `artifacts/results.json`。
- 所有融合权重为预注册固定值；没有用 valid 搜索比例、阈值或选择器。
- 预测和逐项指标保存在 `artifacts/predictions.npz`，汇总保存在 `artifacts/results.json`。

该 valid 已多轮参与方法开发，91.569% 仍是开发集结果，不能作为独立泛化或抗时间漂移确认。RF 融合只用于判断互补信息，不进入“通用生成器”主结果。

## 后续

将固定多数投票作为当前自有系统的集成候选，同时单独开展“局部生成器 token＋全局统计特征支路”的有界对照。该结构方向针对 RF 相对神经模型的剩余优势，比继续扫描学习率更有依据。未来日期评价保持关闭，直到方法版本、对照和输入权限冻结。
