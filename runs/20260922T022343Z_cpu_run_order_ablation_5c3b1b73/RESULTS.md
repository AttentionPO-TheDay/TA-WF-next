# 实验结果

## 同容量顺序消融完成

2026-09-22。exact/coarse 两种 run 视角分别比较原序与固定乱序，使用完全相同的两层卷积模型、初始化规则、minibatch顺序和训练预算；训练 seeds 1729、3407、2026。每个角色的有效 token 在整行内固定随机排列，token 完整字段、mask和多重集保持不变。source训练、valid选模，JP/subpage仅评分。

下表为三个训练seed的accuracy均值；括号是原序减乱序的配对均值，单位pp。

所有18个accuracy配对差均为正：两个视角 × 三个角色 × 三个训练seed。预注册条件要求某视角在valid与JP的三个seed均为正；exact和coarse都通过。macro-F1的18个配对差也全部为正。

## 结论

这轮隔离了上一实验的容量混杂：同一模型下，保留run token排列稳定优于固定乱序。因此可以认为run的排列顺序是当前生成表示中的有效分类信息，不能用无序mean/max池化评价run生成器。

结论仍有限。乱序后每个token携带的邻居bin差和边界字段没有删除，因而对照不是“完全无顺序信息”；只有一个固定排列seed，三个重复是训练seed，不是数据或日期重复。JP/subpage不是时间日期。这支持保留run顺序和使用顺序编码器，但尚未证明抗时间漂移、优于packet/window或分级路由有效。
